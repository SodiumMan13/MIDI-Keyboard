# MIDI-Keyboard
A MIDI keyboard with capacitive touch keys, sliders, push switches, and a rotary encoder

I made this MIDI keyboard for the 3rd week of Half-Life. It has 8 capacitive touch keys, 2 slider potentiometers, 3 key switches, and a rotary encoder. The PCB is 99x99 mm.

The parts can be sourced from Digi-Key, AliExpress, and JLCPCB. The total will be about 30 dollars from those.

For the firmware, you can use CircuitPython for the Waveshare ESP32-S3 Zero. This article explains what you can do: https://github.com/KMKfw/kmk_firmware/blob/main/docs/en/Getting_Started.md
